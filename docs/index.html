MM POS Desk

POS & inventory management for shops — daily sales, stock, purchases, customers and suppliers in one self-hosted web app. Built by Min SiThu with Python, Django and SQLite. MIT licensed.

Run the real app in GitHub (no external host)

  1. Click Open live preview in GitHub Codespaces and choose a 2-core machine. Setup installs dependencies, runs migrations and checks the project.
  2. In the Codespace terminal, run: python3 start.py --no-browser
  3. When port 8001 forwards, open it from the preview prompt or the Ports tab. That is the real app.
  4. Select Create business, then Settings & team → Load sample inventory to try the POS.
  5. Stop the Codespace when you are done, to save your free quota. Data lives in that Codespace only — it is a demo, not a shared production shop.

What it does

Point of sale

Product search, barcode-scanner input, fixed discounts, percentage tax, cash tender and change. Prices are calculated on the server, and stock is checked before checkout.

Inventory

SKU, barcode, category, selling price, reference cost and reorder levels. Multiple warehouses, purchases, adjustments, transfers and full movement history.

Receipts & returns

Printable receipts, sales history, and full-sale returns that restore stock. Reports include date sales, payment-method totals, estimated gross margin and CSV export.

Workspaces & team

Separate business workspaces, owner and cashier roles, and customer / supplier records. Currencies: MMK, THB or USD per workspace.

Run it locally instead

python3 start.py

Then open http://127.0.0.1:8001/ and create a business. Full instructions are in the repository README.
