MM POS Desk

POS & inventory management for shops — daily sales, stock, purchases, customers and suppliers in one self-hosted web app. Built by Min SiThu with Python, Django and SQLite. MIT licensed.

View source on GitHub Read the project overview
What this page is: a static preview of the project. GitHub Pages cannot run the Django backend or its database, so this page does not log you in or record sales. To run the real app, clone the repo and follow the quick start below.

What it does

Point of sale

Product search, barcode-scanner input, fixed discounts, percentage tax, cash tender and change. Prices are calculated on the server, and stock is checked before checkout.

Inventory

SKU, barcode, category, selling price, reference cost and reorder levels. Multiple warehouses, purchases, adjustments, transfers and full movement history.

Receipts & returns

Printable receipts, sales history, and full-sale returns that restore stock. Reports include date sales, payment-method totals, estimated gross margin and CSV export.

Workspaces & team

Separate business workspaces, owner and cashier roles, and customer / supplier records. Currencies: MMK, THB or USD per workspace.

Run it locally

Requires Python 3.11 or newer.

git clone https://github.com/itsmeminsithu/MM-POS-Desk-Inventory-Management.git
cd MM-POS-Desk-Inventory-Management
python3 start.py

Then open http://127.0.0.1:8001/, choose Create business, and register in the browser. There is no default password. Full instructions are in the repo README, and deployment notes in DEPLOYMENT.md.

Project structure

config/    Django settings, URLs, WSGI
retail/    models, views, forms, services, tests, migrations
templates/ HTML templates (retail/, registration/)
static/    app.css, app.js, pos.js
docs/      this static preview page

Payments in the app are records of payments collected outside the app — it does not process cards, verify bank settlements, or create MMQR payloads. Read SECURITY.md before public hosting.
